# Vremenska prognoza interfejs
Responzivan interfejs za aplikaciju vremenske prognoze, rađen u HTML5 i CSS3 sa korištenjem Font Awesome za ikonice.
## Planirane nadogradnje
- Povezivanje sa OpenWeatherMap API-jem putem js ('fetch') za prikaz stvarne statistike vremena određenog grada,
- Dinamička izmjena ikonica u zavisnosti od prave vremenske prognoze,
- Prikaz tačnog vremena uživo i funkcionalna pretraga gradova.
